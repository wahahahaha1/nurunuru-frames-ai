NuruNuru Frames AI
==================

YouTube とニコニコ動画を、ブラウザ内（WebGPU）で AI（RIFE 4.25）と従来方式（ブロックマッチング）を組み合わせてフレーム補間し、
ディスプレイのリフレッシュレート（120Hz / 144Hz / 180Hz など）でなめらかに再生する拡張機能です。
NuruNuru Frames（ブロックマッチング版）の別版です。ページの UI、コメント、全画面などはそのまま使えます。

※ 実機の GPU での速度はまだ計測していない試作版です。

動作環境
--------
- Chrome / Edge / Vivaldi などの Chromium 系ブラウザ（バージョン 116 以降）で、WebGPU が使えること
  （アドレスバーに chrome://gpu または vivaldi://gpu を入力し、「WebGPU: Hardware accelerated」と出ていれば使えます）
- 単体 GPU が必要です（通常版より重い処理です）。重すぎる場合は自動で画質を下げ、それでも足りなければ補間を止めます

インストール
------------
1. このフォルダ（manifest.json が入っているフォルダ）を好きな場所に置きます（使っている間は消さないでください）
2. ブラウザで拡張機能の管理ページを開きます
   Chrome: chrome://extensions   Edge: edge://extensions   Vivaldi: vivaldi://extensions
3. 「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選びます

使い方
------
- 動画を再生すると、AI モデルを読み込んでから自動で補間が始まります
- Alt+Shift+S で ON/OFF、Alt+Shift+D で比較表示（左: 元映像 / 右: 補間）を切り替えます
- ツールバーのアイコン（紫の再生マーク）から、目標フレームレート、画質プリセット、ブロックマッチングとの併用、
  アニメの作画（2 コマ・3 コマ打ち）に合わせる設定などを変えられます
- 通常版の NuruNuru Frames が動いている動画では、AI 版は自動で停止します。比べるときは片方をオフにしてください

できないこと
------------
- DRM で保護された動画（有料映画など）は補間しません（元の映像のまま表示します）
- 広告の除去、データの収集・送信は一切行いません
  （ポップアップの「3 秒記録」は、検証用に数秒分の元フレームと補間映像を手元に保存するだけです）
